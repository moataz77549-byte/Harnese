# Harnese Nova 4.0.0 — مركز البناء وتجربة الاستخدام

يجمع المرحلتين 3.3 و4.0 على أساس 3.2.0. رقم البناء 31، لهواتف ARM64 بنظام Android 8 فأحدث.

- اختيار بناء Release APK أو Android App Bundle من مركز البناء، باستخدام إعدادات Gradle الخاصة بالمشروع. تحديد المخرجات من نوع البناء الصحيح والتحقق من بنيتها، وحفظ نسخة منها. يمكن نسخ SHA-256 وتعرض شهادة APK عندما يمكن قراءتها. لا ينشئ Harnese مفاتيح جديدة للمشاريع.
- فحص حالة Git الحقيقية داخل المشروع وقائمة Git الموسعة لعرض الفروع والسجل والتغييرات، وفحص المستودع المرتبط، وتجهيز أوامر المزامنة والالتزام والدفع في طرفية المشروع لمراجعتها وتشغيلها يدويًا.
- بحث في المشاريع، وتصفية مشاريع Android، وإظهار تبويب المراجعة في شريط التنقل. البحث في نصوص الملفات على مستوى المشروع ضمن حدود واضحة وإمكانية فتح موضع النتيجة.
- تحسين الترجمات الناقصة في الإسبانية والروسية والهندية والصينية، ومعالجة تنسيق الكود.
- الحفاظ على النسخ الاحتياطية والمسودات وتبويبات الملفات وسجلات الطرفية في 3.2.0.
- اختبار بناء قالب Android بنسخ Debug وRelease وAAB، والتحقق من الهوية والتوقيع والترقية فوق 3.2.0.

تظل مصادقة المزودين الفعلية، وتشغيل Linux على الهواتف، وتجربة واجهات المستخدم الميدانية مطلوبة. يعتمد توقيع مشاريع المستخدم على إعدادات المشروع؛ قراءة شهادة APK في التطبيق ليست اختبار apksigner كاملًا.
