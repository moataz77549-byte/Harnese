# Harnese Nova 2.3.0

يجمع هذا التحديث المرحلتين 2.2 و2.3. من قائمة المجلد في شاشة الملفات يمكنك فتح طرفية Linux فيه أو اعتماده جذرًا للمشروع. ومن قائمة الجذر يمكنك العودة إلى مساحة العمل الكاملة. يحتفظ المحرر بالأسطر النهائية التي كتبتها. وتعرض شاشة البيئات حالة Ubuntu وPRoot والمساحة المتاحة دون حساب حجم شجرة Linux عند كل فتح.

يحدد مركز البناء جذر Gradle ويتعامل مع مجلدات debug الخاصة بالنكهات، ويعرض بصمة SHA-256 قابلة للنسخ. عند وجود مشروعين مستقلين اختر المجلد المقصود قبل البناء. يعرض فحص GitHub حالة الأرشفة وصلاحية الدفع عندما يعيدها GitHub. يستخدم Telegram سجل المشروع المختار ويتحقق من ملف البناء قبل الإرسال. تربط شاشة MCP نتائج الاتصال والمراجعة بالخادم والمشروع والوكيل المختارين.

إصدار تجربة ARM64 لأندرويد 8 فأحدث، برقم بناء 27. جرّبه بالتثبيت فوق 2.1 ثم افتح مشروعًا سابقًا واختبر البناء منه.
